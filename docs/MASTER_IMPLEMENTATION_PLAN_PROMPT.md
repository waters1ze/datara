## ЭТАП 1. СИНТАКСИЧЕСКАЯ ГИГИЕНА И СИСТЕМА ПЕРЕМЕННЫХ («ТРИАДА ТРЕХ БУКВ»)

### Задача:
Устранить хаос объявлений (`:=`, `let mut`, `=`, `mut sum`). Ввести строгое, красивое и запоминающееся правило 3-х букв:

1. **`let` (Статика, Неизменяемая)**:
   - Синтаксис: `let x: Int = 10` или с автовыводом: `let x = 10`.
   - Семантика: Неизменяемое значение. Повторное присваивание `x = 20` вызывает ошибку компилятора.
   - Компиляция: Напрямую понижается в SSA-значение (`ValueId`), раскладывается в регистр CPU (0 аллокаций в памяти).
2. **`mut` (Статика, Изменяемая)**:
   - Синтаксис: `mut counter: Int = 0` или с автовыводом: `mut counter = 0`.
   - Семантика: Локальное мутабельное состояние в 1 слово (без длинного `let mut`). Тип строго зафиксирован, смена типа запрещена.
   - Присваивание: Работает через стандартный оператор `=`: `counter = counter + 1`.
3. **`val` (Гибридная динамика / Gradual Typing)**:
   - Синтаксис: `val data = fetch_json()` или `mut val payload = 10; payload = "текст"`.
   - Семантика: Универсальный динамический контейнер для работы с внешними API, JSON и быстрыми скриптами.
   - Оптимизация в компиляторе:
     - **Type Promotion**: Если оптимизатор доказывает, что тип не меняется, он автоматически сбрасывает динамику до прямого скаляра.
     - **64-bit NaN-Boxing / Tagged Pointer**: Динамическое значение упаковывается ровно в 8 байт (один регистр CPU) без создания объектов в куче.

## ЭТАП 2. ПЕРЕОСМЫСЛЕНИЕ ООП: ДАТА-ОРИЕНТИРОВАННОСТЬ ПОД МАСКОЙ КЛАССОВ

### Задача:
Дать программисту привычный синтаксис классов и методов, но под капотом компилировать это в плоские структуры данных без скрытых указателей и vtable.

1. **Синтаксис `class` (Чистая разметка памяти + методы внутри)**:
   ```datara
   class User {
       id: u64
       name: Str
       email: Str

       fn get_domain() -> Str {
           return this.email.split("@")[1]
       }
   }
   ```
2. **Физика под капотом (DOP / Zero-Cost Abstraction)**:
   - В памяти `User` — это плоская структура (POD / C-Struct) без служебных метаданных.
   - Вызов `user.get_domain()` понижается в вызов плоской функции `User_get_domain(user)`.
3. **UFCS (Uniform Function Call Syntax)**:
   - Любая функция `fn double(x: Int) -> Int` должна иметь возможность вызываться и классически: `double(x)`, и через точку: `x.double()`, и через пайплайн: `x |> double()`.
4. **Устранение наследования (`from` полностью удалить)**:
   - Замена на **Композицию без вложенности (Flat Embedding / `using`)**:
   ```datara
   class Admin {
       using User       // Поля User автоматически встраиваются в память Admin
       level: u8
   }
   ```
   - Доступ к полям прямой: `admin.name`, `admin.id`. Никакой вложенности объектов в памяти.

## ЭТАП 3. ПОЛНАЯ СИСТЕМА ТИПОВ И УНИКАЛЬНЫЕ ПРИМИТИВЫ

### Задача:
Расширить систему типов Forgen для поддержки микроконтроллеров, системного низкоуровневого программирования и финтеха.

1. **Целочисленные типы фиксированной разрядности**:
   - Беззнаковые: `u8`, `u16`, `u32`, `u64`, `u128`, `usize`.
   - Знаковые: `i8`, `i16`, `i32`, `i64`, `i128`, `isize`.
2. **Числа с плавающей точкой**:
   - `f16` (половинная точность для AI/нейросетей и графики).
   - `f32`, `f64`.
3. **Уникальный банковский тип `dec64` / `dec128` (Fixed Decimal)**:
   - Арифметика с фиксированной запятой прямо в ядре языка для исключения ошибок округления (`0.1 + 0.2 = 0.3`).
4. **Битовые структуры (`packet`)**:
   - Синтаксис упаковки бит для драйверов и протоколов:
   ```datara
   packet TcpHeader {
       src_port: 16
       dest_port: 16
       syn_flag: 1
       ack_flag: 1
   }
   ```
5. **Null-Safety (Строго без `null`)**:
   - Тип `T?` (Опциональное значение: либо `Some(T)`, либо `None`).
   - Smart Type Narrowing: внутри блока `if val != None` тип автоматически сужается до `T` без необходимости писать ручные `unwrap()`.

## ЭТАП 4. ВСТРОЕННЫЕ КОЛЛЕКЦИИ В ЯДРЕ (BUILT-IN ZERO-SETUP COLLECTIONS)

### Задача:
Реализовать первоклассные коллекции прямо в синтаксисе компилятора:

1. **Динамический список (`List[T]`)**:
   - Литерал: `[1, 2, 3]`.
   - Методы: `.push(val)`, `.pop()`, `.len()`, доступ по индексу `list[i]`.
2. **Фиксированный массив на стеке (`Array[T, N]`)**:
   - Литерал: `[0; 256]`.
   - 0 аллокаций в куче, размещается прямо в стековом фрейме или регистрах.
3. **Хэш-таблица (`Map[K, V]`)**:
   - Литерал: `["key": "value"]`.
   - Методы: `.get(k)`, `.insert(k, v)`, доступ `map["key"]`.
4. **Zero-Copy Срезы (`Slice` / `view [T]`)**:
   - Синтаксис: `items[start..end]`.
   - Не копирует память, возвращает безопасное представление (указатель + длина) с проверкой границ в компиляторе.

## ЭТАП 5. БАЗОВЫЕ ФУНКЦИИ ВВОДА-ВЫВОДА И РАНТАЙМ-ПРЕЛЮДИЯ (CORE PRELUDE)

### Задача:
Добавить стандартные встроенные функции языка, доступные без импортов:

1. **Терминальный ввод/вывод**:
   - `println(msg)` — вывод строки с переносом и интерполяцией (`println("Hello, {name}!")`).
   - `print(msg)` — вывод без переноса.
   - `eprintln(msg)` — вывод в поток ошибок (`stderr`).
   - `input(prompt: Str) -> Str` — чтение строки из консоли.
2. **Базовые системные функции**:
   - `len(x)` — длина строки, массива, списка или словаря.
   - `now() -> Time` — текущее время (микросекунды/наносекунды).
   - `panic(msg: Str)` — аварийное завершение с диагностическим дампом.
   - `assert(cond: Bool, msg: Str)` — проверка условий в рантайме.
   - `exit(code: i32)` — завершение процесса с кодом.
3. **Строковый рантайм**:
   - Реализовать **SSO (Small String Optimization)**: строки до 23 байт хранятся прямо в стеке/регистре без обращения к `malloc`.
   - Корректное освобождение памяти конкатенации строк (ликвидация утечек).

## ЭТАП 6. ОБРАБОТКА ОШИБОК И ВЫЗОВ ВНЕШНИХ БИБЛИОТЕК (FFI)

### Задача:
1. **Railway-обработка ошибок (без `try/catch`)**:
   - Оператор **`?`**: автоматический ранний возврат ошибки наверх.
   - Блок **`or { ... }`**: явный перехват и матчинг ошибок на месте:
     ```datara
     let user = load_user(id) or {
         NotFound => User.guest(),
         err => panic("Сбой базы: {err}")
     }
     ```
2. **Нативный C-ABI FFI**:
   - Синтаксис прямого подключения библиотек C/Rust:
     ```datara
     extern "C" fn sqlite3_open(filename: Str, db: mut RawPtr) -> i32
     ```
   - Нулевой оверхед при вызове (прямой ассемблерный `call`).
