ТЕХНИЧЕСКОЕ ЗАДАНИЕ ПО ЭТАПАМ:
════════════════════════════════════════════════════════════════════════════════

1. СИНТАКСИС ПЕРЕМЕННЫХ И ОЧИСТКА УСТАРЕВШЕГО КОДА:
   - Внедрить каноническую триаду:
     * `let x: Type = expr` / `let x = expr` — строгая неизменяемая статика (понижается в чистый SSA ValueId / регистр CPU).
     * `mut x: Type = expr` / `mut x = expr` — строгая изменяемая статика в 1 слово (локальная мутация через оператор '=').
     * `val x = expr` / `mut val x = expr` — гибридная динамика (универсальный NaN-boxed 64-битный контейнер с оптимизацией Type Promotion: если тип не меняется, компилятор сбрасывает его в прямой регистровый скаляр).
   - ХИРУРГИЧЕСКОЕ УДАЛЕНИЕ СТАРОГО СИНТАКСИСА:
     * Запретить оператор `:=`. Парсер при встрече `:=` обязан выдавать ошибку:
       "SyntaxError: Operator ':=' is deprecated. Use 'let' for immutable or 'mut' for mutable variables."
     * Удалить наследование классов `from`.
     * Удалить архаичные блоки `try { ... } catch err { ... }`.
     * Унифицировать двоеточие в типах (`name: Type`) во всех параметрах функций, полях структур и переменных.
     * Зафиксировать имена типов: `Str` (канонический) с алиасом `String`; `Int` = алиас `i64`; `Float` = алиас `f64`.

2. ПЕРЕОСМЫСЛЕНИЕ ООП В ДАТА-ОРИЕНТИРОВАННОСТЬ (DOP):
   - Оставить ключевое слово `class Name { ... }`, но в памяти это 100% C-совместимая плоская структура (POD) без скрытых указателей на vtable и locks.
   - Разрешить объявление методов `fn method(self, ...) -> Ret { ... }` прямо внутри `class`.
   - Внедрить плоскую композицию `using Component` внутри `class`: поля встраиваемой структуры автоматически разворачиваются в текущую структуру с прямым смещением в памяти (zero-cost).
   - Внедрить Uniform Function Call Syntax (UFCS): любой вызов `obj.func()` идентичен `func(obj)` и `obj |> func()`.

3. РАСШИРЕННАЯ СИСТЕМА ТИПОВ:
   - Полная сетка чисел: `u8, u16, u32, u64, u128, usize` и `i8, i16, i32, i64, i128, isize`.
   - Плавающая точка: `f16, f32, f64`.
   - Банковский тип с фиксированной запятой: `dec64` и `dec128` прямо в ядре (для точных финансовых расчетов без float-округлений).
   - Битовые структуры `packet { field: bits_count }` для микроконтроллеров и сетевых протоколов.
   - Строгая Null-Safety: `Type?` (Option/Maybe без null) с автоматическим сужением типа (Smart Type Narrowing).

4. ВСТРОЕННЫЕ КОЛЛЕКЦИИ В ЯДРЕ:
   - `List[T]` с литералом `[1, 2, 3]` (.push, .pop, .len, индексация `[i]`).
   - `Array[T, N]` с литералом `[0; 256]` (стековый массив без обращения к куче).
   - `Map[K, V]` с литералом `["k": "v"]` (.get, .insert).
   - `Slice / view [T]` — срез памяти с нулевым копированием `items[start..end]`.

5. CORE PRELUDE & СТРОКОВЫЙ РАНТАЙМ:
   - Встроенные функции без импортов:
     * `println(msg)` (с интерполяцией строк `"Сумма: {a + b}"`), `print(msg)`, `eprintln(msg)`, `input(prompt) -> Str`.
     * `len(x)`, `now() -> u64`, `panic(msg)`, `assert(cond, msg)`, `exit(code)`.
   - Реализовать SSO (Small String Optimization) в рантайме: строки длиной ≤ 23 байта хранятся непосредственно в стековом буфере без `malloc`.
   - Исправить утечки памяти при конкатенации строк длиннее 23 байт.
