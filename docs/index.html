Engineered for Mechanical Sympathy

Designed from first principles to extract maximum performance from modern x86_64 and ARM64 CPUs.

⚡

Dual-Engine Codegen

Sub-50ms cold compilation with Cranelift JIT for rapid local development. Switch to --llvm for LLVM -O3, LTO, and adaptive SIMD vectorization.

🔬

Evidence Gate Formal Optimizer

Transformations are backed by structural mathematical proof. Countable loops are solved in O(1) time, while structs live inside CPU registers via SROA.

🧩

Post-OOP Data-Oriented Design

Clean separation of data records (entity, packet) from execution logic (behavior). Direct dispatch compiles to raw CALLs without vtables.

🛡️

Zero GC Pauses

Deterministic affine ownership semantics and zero-copy borrowing (view). Never suffer garbage collection latency spikes in high-load services.

🖥️

Universal CPU Portability

Generates code adhering to guaranteed baseline instruction sets (SSE2/NEON), ensuring binaries run seamlessly across 100% of computers without crashing.

💻

All-in-One Developer Toolchain

forgen contains everything: compiler, JIT REPL, test runner, code formatter, linter, LSP server, and C99 header exporter.
