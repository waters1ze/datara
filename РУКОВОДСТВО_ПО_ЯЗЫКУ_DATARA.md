# 1. Архитектурная концепция: Преодоление компромиссов системных языков

На протяжении десятилетий индустрия разработки программного обеспечения находилась в тисках классического «треугольника компромиссов»:

1. **C и C++**: Предоставляют максимальную аппаратную скорость и прямой доступ к регистрам процессора, но накладывают огромную цену в виде уязвимостей памяти: переполнение буфера, утечки памяти, повисшие указатели (`dangling pointers`), состояния гонки данных (`data races`) и ошибки освобождения (`use-after-free`), составляющие свыше 70% критических уязвимостей в современных ОС.
2. **Python, Java, C#, Go, JavaScript**: Обеспечивают высокую скорость разработки и защищенность памяти за счет использования виртуальных машин и автоматических сборщиков мусора (Garbage Collectors). Однако платой за это становятся непредсказуемые паузы остановки мира (Stop-The-World GC pauses), многократный оверхед по оперативной памяти (в 10–50 раз больше, чем у нативных бинарников) и медленный запуск программ.
3. **Rust**: Предлагает гарантию безопасности памяти без сборщика мусора через модель времен жизни (lifetimes) и borrow checker. Однако это привело к колоссальной сложности синтаксиса, крутой кривой обучения, перегруженным сигнатурам типов и крайне длительному времени сборки проектов (десятки секунд и минуты).

### Миссия Datara:
Объединить **лаконичную выразительность Python**, **абсолютную скорость исполнения C** и **статическую безопасность памяти Rust без сборщика мусора**, одновременно сократив цикл компиляции «правка — запуск» до рекордных **30–50 миллисекунд**.

# 3. Собственные оригинальные инновации Datara

В процессе проектирования языка Datara были разработаны и внедрены фундаментальные архитектурные решения:

### 1. Триада переменных с блокировкой типа (`let`, `mut`, `val`)
Язык устраняет путаницу между постоянством привязки и мутабельностью данных:
* `let x = 42` — статическая неизменяемая привязка. Компилятор гарантирует, что значение не изменится после инициализации, и оптимизатор Mem2Reg мгновенно помещает его в регистр CPU.
* `mut y = 10` — строгая изменяемая переменная с **блокировкой типа**. Значение можно переназначать любое количество раз, однако смена типа на лету жестко заблокирована на этапе компиляции.
* `val PI = 3.14159` — компиляторная константа (compile-time value) либо динамический контейнер схемы данных, встраиваемый непосредственно в инструкции процессора.

### 2. Конструкция функционального выбора `decide`
Вместо каскадов `if-else` или избыточных `switch-case` блоков, Datara предлагает первоклассное выражение `decide`:
```datara
let tax = decide {
    income > 100000.0 => 0.20,
    income > 50000.0  => 0.13,
    else              => 0.05
}
```
`decide` возвращает значение, проверяется на полноту условий и компилируется в безветвевые инструкции процессора (`CMOV` на x86_64, `CSEL` на ARM64), гарантируя отсутствие промахов предсказателя переходов (Branch Misprediction).

### 3. Формальный оптимизатор Evidence Gate
В большинстве индустриальных компиляторов оптимизирующие проходы работают эвристически. В Forgen реализован **Evidence Gate**: каждый оптимизирующий проход (SROA, LoopFold, LICM, Branchless Select) обязан сгенерировать криптографический и структурный отпечаток математического доказательства инвариантности. Если инвариант не доказан на 100%, компилятор деградирует операцию до базового безопасного кода.

### 4. Zero-Dependency Embedded Stdlib (Встроенная библиотека в памяти)
Все 33 модуля стандартной библиотеки (работа с файлами, сетевые сокеты, HTTP-клиент и сервер, парсер JSON, криптография SHA-256, многопоточность, базы данных) скомпилированы непосредственно внутрь бинарника компилятора `forgen.exe`. Программа компилируется и работает автономно даже в изолированном контуре без доступа к файловой системе или интернету.

### 5. Пост-ООП декомпозиция (Data & Logic Separation)
В традиционном ООП данные и методы слиты в один монолитный класс, что ведет к «проблеме банана с гориллой и джунглями». В Datara:
* `class` задает исключительно физическое расположение полей в памяти (Memory Layout).
* `behavior` описывает логику и методы, которые могут подключаться, расширяться (`extends`) или замещаться (`replaces`) независимо от самого класса. Доступ к полям экземпляра осуществляется через ключевое слово `this.поле`.

# 4. Математический аппарат и алгоритмы компилятора Forgen

В компилятор Forgen заложен строгий математический аппарат классической теории компиляторов:

### А. Свертка индуктивных циклов Гаусса ($O(1)$ LoopFold)
Для любого арифметического цикла вида:
$$\sum_{i=0}^{N-1} (a \cdot i + b)$$
Компилятор анализирует индуктивную переменную, доказывает отсутствие побочных эффектов в теле цикла и заменяет цикл на вычисление аналитической суммы Гаусса:
$$\text{Sum} = b \cdot N + a \cdot \frac{N \cdot (N - 1)}{2}$$
Сложность исполнения снижается с $O(N)$ до **$O(1)$ за 1 машинный такт CPU**.

### Б. Битовая маскировка деления и остатка
Для операций деления и остатка $x \pmod K$, если оптимизатор доказывает, что константа $K$ является степенью двойки ($K = 2^m$), то инструкция процессора `IDIV` (40–80 тактов) заменяется на битовую операцию `AND` (1 такт):
$$(K > 0) \land ((K \ \& \ (K - 1)) == 0) \implies x \pmod{2^m} \equiv x \ \& \ (2^m - 1)$$

### В. Статическая форма единичного присваивания (SSA) и фронтиры Сайтрона
Компилятор транслирует код в плоский Control Flow Graph (CFG), строит дерево непосредственного доминирования (Dominator Tree) и вычисляет фронтиры доминирования (Dominance Frontiers, DF) по алгоритму Cytron et al.:
$$DF(X) = \{ Y \mid \exists P \in \text{Pred}(Y) : X \text{ dom } P \land \neg(X \text{ sdom } Y) \}$$
На границах фронтиров расставляются минимальные $\phi$-функции, после чего алгоритм Mem2Reg преобразует локальные переменные стека в аппаратные регистры.

### Г. Алгебраическая решетка чистоты эффектов (Effect Lattice Theory)
Каждая функция и выражение анализируются на чистоту и получают ранг в полурешетке эффектов:
$$\bot \sqsubseteq \text{Pure} \sqsubseteq \text{IO} \sqsubseteq \text{Async} \sqsubseteq \top$$
Функции с рангом `Pure` гарантированно не имеют скрытых сайд-эффектов и могут безопасно подвергаться агрессивному инлайнингу (Inlining), удалению мертвого кода (DCE) и выносу инвариантов из циклов (LICM).

# 5. Двухдвижковая архитектура компиляции (Cranelift JIT + LLVM AOT)

Компилятор Datara (`forgen`) использует гибридный двухдвижковый подход:

1. **Cranelift Backend (Быстрая разработка и REPL)**:
   * Специально оптимизирован для сверхбыстрой генерации машинного кода (время сборки **30–50 миллисекунд**).
   * Обеспечивает мгновенный отклик в консоли `forgen repl` / `datara` и при вызове `forgen run`.
2. **LLVM AOT Backend (Релизные бинарники: `forgen build --llvm`)**:
   * Передает оптимизированное промежуточное представление DMIR в кодогенератор LLVM.
   * Выполняет глубокую оптимизацию уровней `-O2` и `-O3`, векторизацию циклов SIMD (AVX2, AVX-512, NEON) и межмодульную оптимизацию во время линковки (LTO).

# 6. Исчерпывающая система типов языка Datara

Datara обладает богатой статической системой типов, охватывающей как высокоуровневые бизнес-абстракции, так и низкоуровневые примитивы системного программирования:

### 6.1. Целочисленные типы фиксированной ширины (Int, Int8..64, UInt, UInt8..64)
| Тип | Размер | Диапазон значений | Назначение |
|:---|:---|:---|:---|
| `Int` | 64 бит | от $-2^{63}$ до $2^{63}-1$ | Стандартный знаковый целый тип по умолчанию |
| `Int8` | 8 бит | от $-128$ до $127$ | Байтовые данные, сетевые протоколы |
| `Int16` | 16 бит | от $-32\,768$ до $32\,767$ | Аудиосэмплы, координаты |
| `Int32` | 32 бит | от $-2 \cdot 10^9$ до $2 \cdot 10^9$ | Индексы, совместимость с C `int` |
| `Int64` | 64 бит | от $-2^{63}$ до $2^{63}-1$ | Идентичен `Int`, таймстемпы, большие счетчики |
| `UInt` | 64 бит | от $0$ до $2^{64}-1$ | Беззнаковый счетчик памяти |
| `UInt8` | 8 бит | от $0$ до $255$ | Бинарные буферы (`byte`) |
| `UInt16` | 16 бит | от $0$ до $65\,535$ | Сетевые порты, кодировки |
| `UInt32` | 32 бит | от $0$ до $4.29 \cdot 10^9$ | Идентификаторы, битовые маски |
| `UInt64` | 64 бит | от $0$ до $2^{64}-1$ | Хеши, криптографические указатели |

### 6.2. Числа с плавающей точкой (Float, Float32, Float64)
* `Float` (64-битный IEEE 754 double precision) — стандартный вещественный тип.
* `Float32` (32-битный single precision) — для 3D-графики, шейдеров и машинного обучения.
* `Float64` (64-битный double precision) — для высокоточных научных расчетов.

### 6.3. Высокоточные десятичные типы (Dec64, Dec128)
* `Dec64` и `Dec128`: типы данных с фиксированной десятичной точкой. Исключают проблемы округления двоичных дробей (такие как `0.1 + 0.2 = 0.30000000000000004` в других языках). Разработаны специально для финтеха, банковских транзакций и биржевых шлюзов.

### 6.4. Логический тип, символы и строки (Bool, Char, Str/String)
* `Bool`: логические литералы `true` и `false`.
* `Char`: 32-битный скаляр Юникода (поддерживает любые символы, включая кириллицу, иероглифы и спецсимволы): `let c: Char = 'Д'`.
* `Str` (или `String`): неизменяемая строка UTF-8, хранящаяся как легковесный срез (указатель + длина) с нулевыми накладными расходами на копирование.

### 6.5. Строковые литералы vs Интерполированные шаблоны (`fmt"..."`)
В языке Datara действует строгое промышленное разделение:
1. **Обычные строковые литералы (`"..."`)**: являются **100% сырым неизменяемым текстом**. Любые фигурные скобки `{переменная}` внутри обычных кавычек воспринимаются компилятором как буквальный текст `{текст}` (как в C#, Rust, Python, C++):
   ```datara
   let pattern = "Шаблон: {name}"
   println(pattern) // Выведет ровно: Шаблон: {name}
   ```
2. **Интерполированные строки (`fmt"..."` / `$"..."` / `f"..."`)**: только наличие префикса `fmt` сообщает компилятору о необходимости интерполяции:
   ```datara
   let name = "Алексей"
   println(fmt"Привет, {name}!") // Выведет: Привет, Алексей!
   ```

### 6.6. Специальные типы: Unit, Never, Val, RawPtr
* `Unit` (записывается как `Unit` или `()`): обозначает отсутствие возвращаемого значения (аналог `void` в C, но является полноправным типом).
* `Never`: тип расходящихся функций, которые никогда не возвращают управление (например, `panic("авария")` или бесконечный цикл диспетчера).
* `Val`: контейнер этапа компиляции или динамической схемы, адаптирующийся к новым полям данных без краха программы.
* `RawPtr`: прямой низкоуровневый указатель на машинную память (используется внутри блоков `unsafe` для взаимодействия с ядром ОС и драйверами).

### 6.7. Кортежи (Tuples) и Диапазоны (Ranges/Slices)
* **Кортежи**: объединяют несколько разнородных типов данных без объявления класса:
  ```datara
  let packet: (Int, Str, Bool) = (101, "ACK", true)
  let code = packet.0
  let msg = packet.1
  ```
* **Диапазоны**:
  * Полуоткрытый: `0..10` (от 0 до 9 включительно).
  * Замкнутый: `0..=10` (от 0 до 10 включительно).

### 6.8. Обобщенные типы (Generics) и монадические типы (Option?, Result!)
* Обобщения задаются в угловых скобках: `List<T>`, `Map<K, V>`.
* **Тип Option (`T?` или `Maybe<T>`)**: безопасно представляет значение или его отсутствие (`None`), полностью исключая ошибку `NullPointerException` (ситуацию «ошибки на миллиард долларов»):
  ```datara
  let maybe_user: Str? = find_user(id)
  ```
* **Тип Result (`T!E` или `Result<T, E>`)**: представляет успешный результат `ok(val)` либо ошибку `error(err)`.

### 6.9. Аппаратные SIMD-векторы (`float4`, `int4`) и векторные интринсики
Datara предоставляет прямой доступ к векторным регистрам процессора (SSE/AVX на x86_64, NEON на ARM):
```datara
let v1 = float4(1.0, 2.0, 3.0, 4.0)
let v2 = float4(5.0, 6.0, 7.0, 8.0)
let product = dot(v1, v2) // Скалярное произведение за 1 такт процессора
let minimum = min4(v1, v2)
```

### Лабораторная работа 2: Моделирование предметной области (ООП + Decide)
```datara
class BankAccount {
    owner: Str
    balance: Float
    is_vip: Bool
    
    tier() -> Str => decide {
        this.balance >= 100000.0 => "Платиновый клиент",
        this.balance >= 50000.0  => "Золотой клиент",
        this.balance >= 10000.0  => "Серебряный клиент",
```

### Лабораторная работа 3: Алгоритм поиска простых чисел (Решето Эратосфена)
```datara
fn is_prime(n: Int) -> Bool {
    if n <= 1 { return false }
    if n <= 3 { return true }
    if n % 2 == 0 || n % 3 == 0 { return false }
    
    mut i = 5
    while i * i <= n {
        if n % i == 0 || n % (i + 2) == 0 {
            return false
        }
        i = i + 6
    }
    return true
}

fn main() {
    println("=== Лабораторная работа 3: Поиск простых чисел ===")
    mut count = 0
    for num in 1..50 {
        if is_prime(num) {
            count = count + 1
            println(fmt"Найдено простое число: {num}")
        }
    }
    println(fmt"Всего найдено простых чисел в диапазоне от 1 до 50: {count}")
}
```
