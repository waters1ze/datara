# 1. Введение: Проблема современных языков и миссия Datara

В современной компьютерной науке сложился фундаментальный компромисс («треугольник компромиссов»):
* **C / C++**: Предельная машинная скорость, но катастрофическая ненадежность памяти (утечки памяти, висячие указатели, переполнения буфера, уязвимости типа use-after-free).
* **Python / JavaScript / Java / C#**: Простота синтаксиса и безопасность, но колоссальные накладные расходы: виртуальные машины, непредсказуемые паузы сборщика мусора (Garbage Collector), пожирание гигабайтов оперативной памяти и медленный старт.
* **Rust**: Высочайшая безопасность и скорость без GC, но чрезвычайно сложная, академически перегруженная семантика времен жизни (`'a`), запутанные сообщения об ошибках и крайне медленная компиляция (десятки секунд на сборку небольшого проекта).

### Цель разработки Datara:
Объединить **лаконичность и элегантность Python** с **механической скоростью C** и **статической безопасностью памяти Rust**, полностью исключив сборщик мусора и сократив время сборки программ до **30–50 миллисекунд**.

# 3. Наши собственные инновации: Где мы придумали свои решения

В проекте Datara мы не просто скопировали существующие подходы, а разработали 5 оригинальных инженерных концепций:

### 1. Триада переменных с блокировкой типа (`let`, `mut`, `val`)
В большинстве языков есть либо 2 состояния (`let`/`const` в JS, `let`/`let mut` в Rust), либо всё мутабельно по умолчанию (Python).
Мы разделили семантику на три фундаментальных уровня:
* `let x = 10` — неизменяемая локальная переменная (значение нельзя переназначить).
* `mut y = 20` — строго мутабельная переменная с **блокировкой типа** (значение можно менять, но компилятор жестко запрещает изменение типа на лету, устраняя 90% скрытых ошибок динамических языков).
* `val PI = 3.14159` — истинная константа этапа компиляции (встраивается прямо в опкоды инструкций процессора).

### 2. Конструкция функционального выбора `decide`
Традиционные конструкции `switch/case` громоздки, а длинные цепочки `if-else` перегружают код шумом. Мы внедрили конструкцию `decide`:
```datara
let status = decide {
    score >= 90 => "Отлично",
    score >= 75 => "Хорошо",
    score >= 60 => "Удовлетворительно",
    else => "Пересдача"
}
```
Она является выражением (возвращает значение), проверяется на полноту охвата условий и компилируется в безветвевые инструкции процессора (`CMOV` / `SELECT`).

### 3. Оптимизатор Evidence Gate (Формальное доказательство корректности)
В классических компиляторах (GCC, Clang) оптимизации работают эвристически (на «авось»). В компиляторе **Forgen** внедрен пайплайн **Evidence Gate**:
Каждый шаг оптимизации (SROA, Mem2Reg, LoopFold) обязан предоставить математический отпечаток доказательства. Если преобразование не доказано формально, компилятор отклоняет потенциально опасную замену.

### 4. Zero-Dependency Embedded Stdlib (Встроенная стандартная библиотека)
Стандартная библиотека из 33 модулей скомпилирована компилятором Rust внутрь самого исполняемого файла `forgen.exe`. Даже на чистом ПК без интернета и без исходных файлов компилятор извлекает библиотечные модули из собственной памяти!

### 5. Безопасные срезы без копирования (`view`)
Вместо сложной системы времен жизни из Rust (`&'a str`), в Datara используется модель `view`:
Срез `view` позволяет читать строки или массивы с нулевым копированием памяти. Компилятор статически гарантирует, что исходный объект не будет изменен или удален, пока активен `view`.

# 4. Математические формулы и алгоритмы внутри компилятора

Внутри компилятора Forgen реализованы классические математические алгоритмы компьютерных наук:

### А. Свертка линейных циклов в замкнутую форму (Evidence Gate LoopFold)
Когда компилятор встречает цикл накопления суммы арифметической прогрессии:
$$\sum_{i=0}^{N-1} (a \cdot i + b)$$
Вместо того чтобы крутить миллиарды итераций в процессоре, оптимизатор применяет доказанную формулу суммы Карла Фридриха Гаусса:
$$\text{Total} = b \cdot N + a \cdot \frac{N \cdot (N - 1)}{2}$$
В результате цикл на $10\,000\,000$ итераций выполняется за **0.00 миллисекунд (за 1 такт процессора, $O(1)$ вместо $O(N)$)**.

### Б. Битовая маскировка деления и взятия остатка
Для операций взятия остатка по модулю $x \pmod K$, если делитель $K$ является степенью двойки ($K = 2^m$), компилятор проверяет инвариант:
$$(K > 0) \land ((K \ \& \ (K - 1)) == 0)$$
И заменяет тяжелую инструкцию процессора `IDIV` (требующую 40–80 тактов CPU) на мгновенную побитовую операцию `AND` (1 такт):
$$x \pmod{2^m} \equiv x \ \& \ (2^m - 1)$$

### В. Построение статической формы единичного присваивания (SSA) и Mem2Reg
Компилятор строит граф потока управления (Control Flow Graph, CFG) и дерево доминаторов (Dominator Tree). По алгоритму Сайтchron (Cytron et al.) вычисляются фронтиры доминирования (Dominance Frontiers):
$$DF(X) = \{ Y \mid \exists P \in \text{Pred}(Y) : X \text{ dom } P \land \neg(X \text{ sdom } Y) \}$$
На основе фронтиров компилятор расставляет $\phi$-функции (phi-узлы) и преобразует локальные переменные памяти из стека в регистры процессора.

### Г. Решетка эффектов чистоты (Effect Lattice Theory)
Каждая функция размечается в алгебраической решетке чистоты:
$$\bot \sqsubseteq \text{Pure} \sqsubseteq \text{IO} \sqsubseteq \text{Async} \sqsubseteq \top$$
Если функция помечена как `Pure` (чистая), компилятор математически доказывает отсутствие побочных эффектов ввода-вывода и свободно выносит ее вызовы из циклов (Loop Invariant Code Motion, LICM).

# 5. Архитектура компилятора: Двойной движок Cranelift + LLVM AOT

Компилятор Datara (`forgen`) использует передовую двухступенчатую архитектуру:

```
                  [ Исходный код .dtr ]
                            │
                     Лексер и Парсер
                            │
               [ Абстрактное синтаксическое дерево (AST) ]
                            │
       Тайпчекер + Решетка эффектов + Affine Borrow Checker
                            │
              [ Промежуточное представление DMIR SSA ]
                            │
         Оптимизатор Evidence Gate (SROA, LoopFold, CSE)
                            │
               ┌────────────┴────────────┐
               ▼                         ▼
      [ Cranelift Backend ]      [ LLVM AOT Backend ]
   Быстрая сборка за 30-40 мс   Пиковая машинная скорость (-O3)
   Интерактивный JIT в REPL     Векторизация SIMD + LTO
               │                         │
               ▼                         ▼
      [ Нативный .exe / ELF машинный бинарный код ]
```

# 6. ПОЛНЫЙ СПРАВОЧНИК ПО СИНТАКСИСУ ЯЗЫКА

### 6.1. Структура программы и точка входа
Точкой входа в любую программу является функция `fn main()`:
```datara
// Однострочный комментарий

fn main() {
    println("Программа запущена!")
}
```
Точки с запятой в конце строк **не требуются**.

### 6.2. Вывод данных и интерполяция строк
Вывод на консоль осуществляется встроенными функциями `println` или `out`:
```datara
fn main() {
    let name = "Алексей"
    let age = 17
    
    // Интерполяция строк через префикс fmt"..."
    println(fmt"Привет, {name}! Твой возраст: {age}")
    
    // Либо конкатенация строк через оператор +
    println("Пользователь: " + name)
}
```

### 6.6. Управляющие конструкции: if, else, циклы for и while

#### Условный оператор `if - else`:
```datara
fn main() {
    let x = 15
    if x > 10 {
        println("x больше 10")
    } else if x == 10 {
        println("x равен 10")
    } else {
        println("x меньше 10")
    }
}
```

#### Диапазонный цикл `for .. in`:
```datara
fn main() {
    // Цикл от 0 до 9 включительно (10 не входит)
    mut sum = 0
    for i in 0..10 {
        sum = sum + i
    }
    println(fmt"Сумма чисел от 0 до 9: {sum}")
}
```

#### Цикл `while`:
```datara
fn main() {
    mut n = 5
    while n > 0 {
        println(fmt"Обратный отсчет: {n}")
        n = n - 1
    }
}
```

### 6.7. Функциональное принятие решений: конструкция decide
Конструкция `decide` вычисляет условия сверху вниз и возвращает соответствующее значение:
```datara
fn get_discount(age: Int) -> Int {
    return decide {
        age < 7  => 100, // Детям бесплатно
        age < 18 => 50,  // Школьникам скидка 50%
        age >= 65 => 30, // Пенсионерам 30%
        else => 0        // Стандартный билет
    }
}
```

### 6.8. Функции и лямбда-стрелки
Функции объявляются ключевым словом `fn`. Тип возвращаемого значения указывается через `->`:
```datara
// Классическая функция с телом в блоке { ... }
fn square(n: Int) -> Int {
    return n * n
}

// Короткая однострочная функция через стрелку =>
fn cube(n: Int) -> Int => n * n * n

fn main() {
    let s = square(5)
    let c = cube(3)
    println(fmt"5^2 = {s}, 3^3 = {c}")
}
```

### 6.9. Объектно-ориентированное моделирование: class и behavior
Datara объединяет структуры данных (`class`) и методы (`behavior`), исключая проблемы глубокого наследования:

```datara
// Объявление структуры данных
class Rectangle {
    width: Int
    height: Int

    // Встроенный метод-геттер
    area() -> Int => width * height
}

// Вынесение поведения (Behavior-driven design)
behavior Rectangle {
    perimeter() -> Int {
        return (self.width + self.height) * 2
    }
}

fn main() {
    let rect = Rectangle { width: 10, height: 20 }
    println(fmt"Площадь: {rect.area()}")
    println(fmt"Периметр: {rect.perimeter()}")
}
```

### 6.10. Безопасность памяти: Affine Ownership и срезы view
В Datara память освобождается в момент выхода переменной из области видимости, без сборщика мусора.
Если вам нужно передать данные без копирования, используйте `view`:

```datara
fn print_message(view text: Str) {
    println("Получено сообщение: " + text)
}

fn main() {
    let msg = "Важные данные"
    print_message(msg) // Передается легковесный view, память не дублируется
}
```

### 6.11. Обработка ошибок без исключений: Result!, Option?, ?, or
Вместо медленного механизма исключений `try / catch`, приводящего к разматыванию стека (stack unwinding), в Datara внедрен явный контроль ошибок:

```datara
// Функция возвращает Result! (число или ошибка)
fn divide(a: Int, b: Int) -> Result!<Int> {
    if b == 0 {
        return error("Деление на ноль недопустимо!")
    }
    return ok(a / b)
}

fn main() {
    // Оператор `or` задает значение по умолчанию при ошибке
    let safe_res = divide(10, 0) or 0
    println(fmt"Безопасный результат: {safe_res}")
}
```

# 7. Практические примеры для самостоятельного запуска

### Пример 1: Алгоритм вычисления факториала и Фибоначчи
Сохраните в файл `test1.dtr` и запустите командой `forgen run test1.dtr`:
```datara
fn factorial(n: Int) -> Int {
    if n <= 1 {
        return 1
    }
    return n * factorial(n - 1)
}

fn fibonacci(n: Int) -> Int {
    if n <= 0 { return 0 }
    if n == 1 { return 1 }
    mut a = 0
    mut b = 1
    for i in 2..(n + 1) {
        let temp = a + b
        a = b
        b = temp
    }
    return b
}

fn main() {
    println(fmt"5! (факториал 5) = {factorial(5)}")
    println(fmt"10-е число Фибоначчи = {fibonacci(10)}")
}
```

class Student {

    grade: Int

        grade >= 90 => "Отличник (5)",

}
