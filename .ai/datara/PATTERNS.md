# Datara Architectural Patterns Index

This index organizes specialized design patterns in `.ai/datara/patterns/`:

- [Comptime & Structural @derive](file:///.ai/datara/patterns/comptime-and-derive-pattern.md): Constant folding and method synthesis without vtables.
- [Async Proactor & Reactive UI](file:///.ai/datara/patterns/async-and-ui-pattern.md): Futures, tasks, event loop, and virtual node diffing.
- [Module Pattern](file:///.ai/datara/patterns/module-pattern.md): Progressive project levels (1, 2, 3), multi-file separation.
- [Error Handling Pattern](file:///.ai/datara/patterns/error-pattern.md): `Outcome<T>`, `Maybe<T>`, `?` operator, and `or` fallback.
- [Collections & Pipelines](file:///.ai/datara/patterns/collection-pattern.md): Dynamic arrays, map wrappers, Stream Fusion.
- [Zero-Trust I/O Pattern](file:///.ai/datara/patterns/io-pattern.md): Capability tokens, secure file/network access.
- [Testing Pattern](file:///.ai/datara/patterns/testing-pattern.md): Structuring tests in `tests/`, assertion protocols.
- [Performance Pattern](file:///.ai/datara/patterns/performance-pattern.md): Mem2Reg promotion, loop vectorization, string templates.
- [ECRP Architecture](file:///.ai/datara/patterns/architecture-pattern.md): Entity, Component, Role, Process paradigm.
- [Fearless Concurrency](file:///.ai/datara/patterns/concurrency-pattern.md): `parallel for`, fork-join parallelism, zero-race guarantee.
